# FinSight — Modern Finance & Analytics Dashboard

FinSight is a modern, responsive finance and analytics dashboard built with React.  
It provides a clean interface for monitoring financial performance, transactions, customers, and account settings.

## 🚀 Features

- 📊 Financial performance dashboard
- 💳 Transaction management
- 🔎 Transaction search and status filtering
- 📈 Revenue analytics
- 📊 Transaction volume analytics
- 👥 Customer management dashboard
- ⚙️ Account and notification settings
- 📱 Responsive design
- 🧭 React Router based navigation
- 📉 Interactive charts using Recharts
- ✨ Modern UI with hover animations and reusable components

## 🛠️ Tech Stack

- React
- JavaScript
- React Router DOM
- Recharts
- Lucide React
- CSS
- Vite
